# 04 — Çok Dil Desteği (i18n)

## Kurallar

1. Kodda hardcoded kullanıcı metni YASAK. Her metin i18n anahtarından gelir.
2. Kütüphane: i18next + react-i18next. Dil dosyaları düz JSON.
3. Başlangıç dilleri: `tr` (ana), `en`. Yapı, yeni dil = tek JSON çevirisi
   olacak şekilde kurulur.
4. Dil seçimi: cihaz dilinden otomatik algıla + ayarlardan elle değiştirme.
   Odadaki herkes KENDİ dilinde oynar (anlatım anahtarları senkron gider,
   metin her cihazda yerel dilde çözülür). TTS kullanılıyorsa host'un dili okunur.
5. İnterpolasyon: `{{name}}`, çoğul kuralları i18next plural ile.
   (İleride Rusça/Arapça gibi karmaşık çoğullu diller için hazır olur.)
6. RTL hazırlığı: layout'ta sabit sol/sağ yön varsayımı yapılmaz
   (Arapça/İbranice ihtimaline karşı Tailwind `rtl:` desteği).

## Dosya Yapısı

```
src/i18n/
  index.ts
  locales/
    tr/
      ui.json          // butonlar, ekran başlıkları, ayarlar
      roles.json       // rol adları + açıklamaları
      narration.json   // moderatör anlatım metinleri
    en/
      ui.json
      roles.json
      narration.json
  STYLE-tr.md          // dil başına üslup notu
  STYLE-en.md
```

## Üslup Notları (STYLE dosyaları)

Anlatım metinleri düz çeviri değil, her dilde "korku hikayesi anlatıcısı"
tadında yeniden yazılır. Örnek üslup notu (tr):
- Anlatıcı sesi: hafif tiyatral, ürkütücü ama mizahtan korkmayan.
- "Siz" hitabı, kısa cümleler, üç nokta serbest.
- Ölüm duyuruları dramatik: "Güneş doğdu… ama {{name}} bir daha uyanmayacak."

## Claude Code Talimatı

- Yeni ekran/özellik eklerken önce anahtarları tr+en JSON'a ekle, sonra UI yaz.
- PR/commit kontrol listesine "hardcoded string taraması" eklenecek
  (basit bir lint scripti: JSX içinde Türkçe/İngilizce düz metin arar).
